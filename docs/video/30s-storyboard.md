# 30秒映像のコンテ（映像制作の練習）

ツール名：タシカメ（仮決定。ウェブ検索では同名の製品なし。J-PlatPat は未確認）
形式：16:9、約30秒。ナレーションは字幕として画面に焼き込む（音声だけに頼らない）
声：利用者の声を録音し、高さを少し下げて使う予定（合成音声は不採用）

## 伝えること（第3案）

1. 日本では自然災害が頻発し、そのたびに病院は患者対応に迫られる
2. 院内の災害対応では、患者対応に追われる中で、患者・人・物がどこにどれだけあるかの把握が難しい
3. 日々の業務に追われ、大規模な訓練を重ねにくい
4. だからタシカメは2つの機能を持つ：災害時に使う実務用の院内調整ツールと、平常時にAIを相手にできる訓練
5. 総合病院から中規模病院まで、安全で効率的な災害時の病院管理と訓練ができる

## 素材の決まり

- 赤十字の標章・名称、日赤の映像や音声は使わない。特定のナレーターの声に似せない
- 報道映像・他団体の動画は使わない。負傷者の映像は入れない
- 素材は、自分たちの画面の録画・自作の図や動き・架空の内容で撮る再現映像（顔は映さない）・商用で使えるフリー素材（実在の病院名・ロゴ・顔が映らないもの）に限る
