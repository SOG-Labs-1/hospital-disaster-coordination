## 振り返り：照合はプログラム、説明文は Claude

訓練が終わると、プログラムが「無線で届いた報告」と「参加者がボードに記録したこと」を照らし合わせ、記録の漏れを指摘します（下の F-01〜F-08 と根拠の番号）。Claude が書いたのは、その説明文だけです。根拠の番号は、プログラムが渡したものしか残しません。

| 指摘 | 根拠 | Claude の説明文（原文のまま） |

## ご自分の API キーで試すとき

```bash
cp .env.example .env
```

`.env` の `ANTHROPIC_API_KEY=` にキーを入れます（モデルは `.env.example` に `claude-sonnet-5-5` が入っています）。

```bash
AI_PROVIDER=anthropic npm run demo
```

訓練モード http://localhost:4600/?hospital=claude&terminal=hq&mode=training の「訓練」タブでシナリオを始めます。訓練タブの「部署役：Claude（AI）」の表示で、Claude が演じていることを確かめられます（APIを使わないときは「mock（APIを使わない決まった返事）」と出ます）。上の記録の回では、部署役の呼び出しは12回、振り返りの説明文は1回でした。
