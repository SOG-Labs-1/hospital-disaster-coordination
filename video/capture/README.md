# 画面の録画素材（紹介映像用）

3分の紹介映像（原稿 `docs/video/3min-script.md`）に差し込む、実際の画面の録画です。
データはすべて架空（`scripts/demo/seed.ts`）。訓練の部署役は `AI_PROVIDER=mock` で、Claude API は使っていません。

## 撮り方

```bash
npx tsx video/capture/record.ts
```

一部だけ撮り直すときは `npx tsx video/capture/record.ts c e` のように書きます（実行のたびにデータを入れ直します）。

- 録画専用のポート（サーバー 4200、画面 5175）と保存先 `video/.capture-data` で起動し、終わったら止めます。通常の `data/` と `e2e/.tmp` には書き込みません。ポートが使用中なら止まります。
- 起動後に `scripts/demo/seed.ts` が API 経由で架空データを入れます。中身は患者5人（P-001〜P-005）、到着済みの搬送 T-001、了承と要員の割り当てまで済んだ搬送 T-002、支援要請 S-001（外来ホールへの車いす2台）、4か所の人数と受け入れ可否です。病棟などは報告がないので「未確認」と表示されます。
- 録画には Chrome の画面配信（CDP の screencast）を使います。1440×810 の画面を 4/3 倍の密度で描いて受け取るので、1920×1080 で文字がくっきり写ります。受け取ったコマは Playwright に同梱の ffmpeg で 30fps の webm（VP9）にします。PC に ffmpeg を入れなくても撮れますが、同梱版は mp4 を書けないため webm にしています。
- 操作は人の速さに合わせてゆっくり行い、マウスの位置は青い丸で写します（ヘッドレスのブラウザでは本物のカーソルが写らないため）。
- 確認用：`npx tsx video/capture/contact-sheet.ts <webm> <出力フォルダ> [秒 ...]` で、指定した秒のコマを PNG に書き出せます。

## 出力（`video/public/captures/`、git 管理外）

すべて 1920×1080、30fps、webm（VP9）、音声なしです。秒数とファイル名の一覧は `manifest.json` にもあります。各クリップの秒数は実行ごとに少し変わります（下の時刻はおよその値）。4〜8秒より長いクリップは、Remotion の `startFrom` と `endAt` で必要な区間だけを使ってください。

### 映像に入れるときの注意

- 災害運用の画面（a〜d、f）は上部に「■ 災害運用」、訓練の画面（e）は「訓練」と表示されています。切り取るときも、この表示が見えるように残すことを勧めます（CLAUDE.md の決まり：画面に常に災害運用／訓練を表示する）。
- 時刻の表示は撮った時刻（深夜）のままです。
- 病院名「Claude総合病院(仮)」、職員名、患者の特徴はすべて架空です。
